# Security Policy

This repository is an archived experiment and is not maintained. Please do not rely on it in production.

If you still find a security problem (for example a leaked secret or personal data), report it privately with GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue. Never include real secrets or personal data in a report; describe where they appear instead.

The maintainer answers on a best-effort basis; no fix date is promised.
